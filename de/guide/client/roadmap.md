# Client Roadmap

| Feature                             | Status  | Hinweise                                         |
| ----------------------------------- | ------- | ------------------------------------------------ |
| Player Events API                   | Geplant | Server Events in Client Events umwandeln         |
| Reconnect Logik (WS + REST)         | Geplant | Backoff & Wiederaufnahme bei transienten Fehlern |
| Eingebaute lokale Queue Abstraktion | Offen   | Optional; Server verwaltet bereits Queue         |
| Such‑Helper (YouTube/Spotify)       | Offen   | Würde Resolver nutzen oder externe APIs          |
| Opus Unterstützung (wenn Server)    | Zukunft | Sobald Server Opus WS Stream anbietet            |
| Metriken / Health Integration       | Zukunft | An zukünftigen Metrics Endpoint anbinden         |

Vorschläge gern via Issue / PR.
